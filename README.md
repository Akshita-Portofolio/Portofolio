# Akshita — Portfolio

A responsive student developer portfolio using **HTML, CSS, Python and Java**.

## Stack
- HTML5 + CSS3 — portfolio interface
- JavaScript — contact form interaction
- Python + Flask — contact API
- Java — OOP Student Project Hub showcase
- GitHub — source control

## Run the Python backend
```bash
pip install -r requirements.txt
python app.py
```
API: `http://127.0.0.1:5000`

## Run the Java project
```bash
javac StudentProjectHub.java
java StudentProjectHub
```

## Frontend
Open `index.html` in a browser. Start the Python API first if you want the contact form to submit.

## Customize
Update the About, Skills, Projects and Contact sections in `index.html` with your own details and links.
